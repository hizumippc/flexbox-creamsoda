# のせのせクリームソーダ（試作）

メロンソーダにアイスをのせながら Flexbox を覚える CSS ゲームです。
サーバーなし。index.html をダブルクリックすればブラウザで遊べます。

## 中身
- index.html … 画面
- style.css … 見た目
- script.js … 問題づくり・採点・シェア

## 公開するとき（GitHub Pages）
1. GitHub に新しいリポジトリを作り、この3ファイルを置く
2. Settings → Pages で main ブランチを公開する
3. script.js の先頭 CONFIG を書きかえる
   - publicUrl … 公開URL（設定済み: https://hizumippc.github.io/flexbox-creamsoda/）
   - gaId … Googleアナリティクスの測定ID（G-から始まるもの）。空なら読み込みません

## 遊び方のしくみ
- 全10問。問題は毎回ランダムに作られます
- 練習モード：1問10点。ミス1回で-2点。「ヒント」（-3点、1回）で、その問題で使うプロパティと説明が出る（値は出ない）。「答え（スキップ）」は答えを見てその問題0点
- 挑戦モード：ヒントなしで1問100点
  - 正確さ60点（ミス1回で-15点、最低15点）
  - 速さ30点（プロパティ1つの問題なら10秒以内で満点、40秒で0点。プロパティが増えると時間も延びる）
  - 無駄のなさ10点（最短の行数より1行多いごとに-5点）
  - 配点は script.js の CHALLENGE で変えられます
- 答え方は「選択式・補助入力・自由入力」をいつでも切りかえられます（最初は選択式）
- 選択式はプロパティ名と値の両方を選びます。最初は1行で、＋で行を足し、×で消します
- 正解すると、最短の答えを全部（何通りかあれば並べて）表示し、多かった行には理由を出します
- 点線の枠がFlexboxの箱のはしです。ミスすると、ズレたアイスが赤く光ります
- 結果のシェアリンクに問題の番号（seed）とモードが入るので、友だちも同じ問題で遊べます
- 1〜3問目 justify-content、4〜5問目 ＋align-items、6〜7問目 縦並び（column）、8〜10問目 逆向き（reverse）と味の順番
